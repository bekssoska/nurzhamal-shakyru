# Туған күнге шақыру — сайт-приглашение

Мобильный сайт-приглашение на казахском языке. Чистый HTML + CSS + JS: без фреймворков, без сборки и без тяжёлых библиотек. Работает на Netlify, Vercel и GitHub Pages как обычные статичные файлы.

```
nurzhamal-shakyru/
├── index.html          разметка и SVG-орнаменты
├── config.js           ← ВСЕ ДАННЫЕ ЗДЕСЬ
├── css/style.css       оформление, темы altyn / zumyrat
├── js/main.js          календарь, таймер, музыка, анкета → WhatsApp
└── assets/
    ├── favicon.svg, favicon-32.png, apple-touch-icon.png
    ├── og-image.jpg    картинка для превью ссылки в WhatsApp (1200×630)
    ├── music.mp3       (положите сами, необязательно)
    └── photo.webp      (положите сами, необязательно)
```

## Как поменять данные

Откройте `config.js` в любом текстовом редакторе и меняйте только то, что в кавычках:

| Поле | Что это | Пример |
|---|---|---|
| `theme` | Цветовая тема | `"altyn"` (золото + бордо) или `"zumyrat"` (золото + изумруд) |
| `name` | Имя | `"Нұржамал"` |
| `age` | Возраст. Если `""`, блок скрыт. Если `"60"`, на обложке крупно «60 жас» | `""` |
| `date` | Дата в формате ГГГГ-ММ-ДД | `"2026-12-05"` |
| `time` | Время | `"12:00"` |
| `timezone` | Часовой пояс для таймера (Казахстан = UTC+5) | `"+05:00"` |
| `venue.village` / `venue.name` | Адрес и название зала | `"Жаңабұлақ ауылы"`, `"«Әулет» мейрамханасы"` |
| `venue.mapUrl` | Ссылка на 2GIS / Яндекс / Google Maps | `"https://2gis.kz/..."` |
| `whatsapp` | Номер для ответов: только цифры, с кодом страны, без `+` | `"77712488056"` |
| `texts` | Все тексты сайта: обращение, заголовки, варианты ответов, текст WhatsApp-сообщения | — |

Календарь, день недели («сенбі»), дата на обложке и в футере, а также таймер считаются автоматически из `date` и `time`. Отдельно их менять не нужно.

### Превью в WhatsApp (OG-теги)

WhatsApp не выполняет JavaScript, поэтому заголовок и описание превью записаны прямо в `index.html` (блок `<meta property="og:...">` в `<head>`). При смене имени или даты поменяйте там:

- `<title>`, `og:title`, `twitter:title`
- `description`, `og:description`, `twitter:description`
- **После деплоя** замените `https://example.com/` на настоящий адрес сайта в `og:image`, `twitter:image` и `og:url`. WhatsApp показывает картинку только по полному адресу, например `https://nurzhamal.netlify.app/assets/og-image.jpg`.

Если меняется имя или дата, обновите и картинку `assets/og-image.jpg` (1200×630, JPG). Можно сделать её в Canva.

## Музыка

Положите файл в `assets/music.mp3`. Лучше всего MP3 128 kbps длиной 2–4 минуты, около 2–4 МБ: так он быстро грузится на мобильном интернете.

- Сама музыка не включается (браузеры это запрещают). Она стартует, когда гость коснётся обложки или нажмёт круглую кнопку ▶ внизу справа.
- **Если файла нет, кнопка и подсказка «Әуенді қосу үшін түртіңіз» просто не появляются.**
- Другое имя файла укажите в `music: "assets/..."`. Чтобы отключить музыку совсем, поставьте `music: ""`.

## Фото

Положите фото в `assets/photo.webp`: квадратное, примерно 600×600, до 100 КБ. Оно появится в круглом медальоне на обложке.

- WebP можно получить на squoosh.app: загрузите JPG и выберите WebP с качеством 75–80.
- Если фото нет, на его месте показывается орнаментальный медальон (шаңырақ и қошқар мүйіз).
- Отключить фото: `photo: ""`.

## Номер WhatsApp

Поменяйте `whatsapp` в `config.js`, например `"77011234567"`. Кнопка «WhatsApp арқылы жіберу» откроет чат с этим номером и уже готовым сообщением:

```
Туған күнге шақыруға жауап 🎉
Аты-жөні: …
Жауабы: …
Тілегі: … (или «—»)
```

На телефоне откроется приложение WhatsApp, на компьютере — WhatsApp Web в новой вкладке. Гостю остаётся нажать «Жіберу». Ответы собирать никуда не нужно: они приходят прямо в WhatsApp.

## Проверка на своём компьютере

Откройте `index.html` двойным кликом. Или, чтобы всё работало как на хостинге, запустите в папке проекта:

```bash
python3 -m http.server 8000
```

и откройте http://localhost:8000.

## Деплой

### Netlify (проще всего)
1. Зайдите на https://app.netlify.com/drop.
2. Перетащите в окно **всю папку** `nurzhamal-shakyru`.
3. Получите адрес вида `https://xxxx.netlify.app`. В Site settings → Change site name можно задать красивое имя.
4. Пропишите этот адрес в `og:image` / `og:url` в `index.html` и перетащите папку ещё раз (Deploys → drag & drop).

### Vercel
1. Установите CLI: `npm i -g vercel`.
2. В папке проекта выполните `vercel`, а затем `vercel --prod`. Настройки сборки не нужны: это статичный сайт.

### GitHub Pages
1. Создайте репозиторий и загрузите в него содержимое папки (`index.html` должен лежать в корне).
2. Settings → Pages → Source: **Deploy from a branch** → `main` / `root`.
3. Через минуту сайт появится по адресу `https://<логин>.github.io/<репозиторий>/`.

> После правок `config.js` на хостинге телефон гостя может какое-то время показывать старую версию из кэша. Если нужно обновить срочно, поменяйте в `index.html` строку `<script src="config.js">` на `<script src="config.js?v=2">`.

## Что проверено

- Ширина 375px (телефон) и 1440px (компьютер: карточка по центру, горизонтального скролла нет).
- Шрифты Cormorant Garamond и Montserrat содержат все казахские буквы: ә ғ қ ң ө ұ ү һ і, строчные и заглавные.
- Календарь: 1 декабря 2026 приходится на вторник (сс), 5 декабря — на субботу (сн), подпись «5 желтоқсан 2026, сенбі».
- Ссылка wa.me корректно кодирует казахские буквы, эмодзи и переносы строк (`%0A`).
- Если дата уже прошла, таймер заменяется на «Тойымызға келгендеріңізге рахмет!».
- Если в системе включено «уменьшение движения» (`prefers-reduced-motion`), анимации отключаются.
